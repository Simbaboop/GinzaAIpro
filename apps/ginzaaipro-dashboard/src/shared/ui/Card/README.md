# Card

## Purpose

Card is the base content container for GinzaAIpro UI surfaces.

It provides a consistent visual wrapper for operational information, intelligence panels, journey views, health metrics, and recommendation displays.

---

## Responsibilities

Card owns:

- container styling
- optional title rendering
- optional description rendering
- consistent spacing
- consistent border and background

---

## Non-Responsibilities

Card does not own:

- business logic
- data loading
- platform state
- feature behavior
- routing

---

## Usage

Use Card whenever a feature needs to display a bounded unit of operational information.
