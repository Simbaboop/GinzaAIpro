# Operational Nervous System (ONS)

## Purpose

The Operational Nervous System propagates operational signals across GinzaAIpro.

It transforms runtime events into actionable signals that can be consumed by Health, Cognition, Recovery, Governance, and future runtime capabilities.

---

## Core Distinction

Runtime Events describe platform reality.

Operational Signals describe operational importance.

An event says:

"Something happened."

A signal says:

"Something needs attention."

---

## Responsibilities

The Operational Nervous System owns:

- signal modeling
- signal publication
- signal subscription
- signal propagation
- signal priority
- future signal routing

---

## Non-Responsibilities

The Operational Nervous System does not own:

- diagnostics
- business health
- recovery decisions
- governance approval
- execution
- user interface rendering

Those belong to Operational Cognition, Operational Health, Recovery, Governance, Execution, or Experience layers.

---
