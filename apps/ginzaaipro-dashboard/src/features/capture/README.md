# Capture Feature

## Purpose

The Capture feature is the first customer-facing entry point into GinzaAIpro.

It allows users to record operational reality as structured evidence.

---

## Responsibilities

Capture owns:

- user-facing capture workflow
- capture form
- capture-specific model
- capture service
- conversion of user input into Operational Evidence

---

## Non-Responsibilities

Capture does not own:

- evidence storage policy
- knowledge graph reasoning
- memory logic
- health scoring
- cognition
- governance
- execution

Those belong to the platform layers.

---

## Canonical Flow

User input
↓
Capture Form
↓
Capture Service
↓
Operational Evidence
↓
Operational Knowledge Graph
↓
Operational Memory
↓
Operational Intelligence
