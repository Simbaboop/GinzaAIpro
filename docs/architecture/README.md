# GinzaAIpro Architecture

## Purpose

This folder contains the canonical architecture governance documents for GinzaAIpro.

These documents define how the platform is structured, how subsystems relate, and which architectural principles must be preserved as the platform evolves.

---

## Scope

This architecture applies to GinzaAIpro implementation.

It does not replace HCOD.

HCOD defines constitutional principles across the broader ecosystem.

GinzaAIpro architecture defines how those principles are engineered into this platform.
