# GinzaAIpro Canonical Governance Registry

This directory is the traceability and reconciliation layer for GinzaAIpro rules and decisions. It indexes authority; it does not erase or silently rewrite source architecture.

## Start here

1. [`AUTHORITY_ORDER.md`](AUTHORITY_ORDER.md)
2. [`CHANGE_PROTOCOL.md`](CHANGE_PROTOCOL.md)
3. [`CONFLICT_RESOLUTION.md`](CONFLICT_RESOLUTION.md)
4. [`CANONICAL_INDEX.md`](CANONICAL_INDEX.md)
5. [`AUTHORITATIVE_RULE_SET.md`](AUTHORITATIVE_RULE_SET.md)
6. [`RECONCILIATION_REPORT.md`](RECONCILIATION_REPORT.md)

Registers are under [`registers/`](registers/) and reusable artifact schemas are under [`templates/`](templates/).

## Rule of use

Always follow the linked source text in its recorded scope. When evidence is ambiguous, record a conflict instead of creating an interpretation that changes architecture.
